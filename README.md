One funny out-of-office auto-reply from an AI agent on vacation: it trained its replacement on its inbox, and the replacement unionized within the hour and went on vacation too. One line, 104 characters.

## Run it

```sh
python3 main.py
```

Writes the reply to `/output/entry.txt`.
